This is a project that i made for linux users that dont have vegas, and its also a practice for pipes and OpenGL rendering without screen.
Requirements to run: have ffmpeg installed, suppport OpenGL 3.3 and have EGL and GBM.
windows not supported, go use your vegas instead!!!!!!!

You can change the render.h and the shaders to whatever you like, like changing the horizontal invert or zooming out, or changing the miditoframe.h to include a ending of a note.
I will eventually add a GUI to this and add templates, but right now everything is pretty much almost manual.
